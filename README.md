Bash Tanks CLI is an ASCII artillery game for linux terminal or frambuffer tty, 
single bash script with no dependencies , tested working inside a screen session 

- No X11 required
- runs on framebuffer tty (1024x768)
- runs inside a gnu screen session
- No installation

  # How to Run:
 # chmod +x bashtanks.sh
 # ./bashtanks.sh
